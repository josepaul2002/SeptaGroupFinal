# Collaborator approval before publication

1. Save the collaborator as **Draft** in Admin → Partners. Upload only material you may share for review.
2. Under **Collaborator approval**, create a seven-day link and copy it. After deployment, the link uses the site's HTTPS origin. A localhost link works only on the same Mac.
3. Send the link to the collaborator using your own approved contact channel. They can inspect the text and media, then approve or request changes with a comment.
4. Read their response in Admin → Partners. The response records a self-declared name and optional email; confirm their identity directly before treating it as formal permission.
5. If you change the profile, the old link stops working. Save the revised draft and create a new link. You can revoke a link at any time.
6. Once a link has been created for a draft, its latest review must approve that exact version before the admin can publish it. An editor cannot publish; an owner or publisher confirms factual accuracy and permissions in the normal publication step.

The page is omitted from search, uses an unguessable token, expires and cannot be used to respond twice. It is a review workflow, not a legal signature service. Uploaded media URLs may be directly accessible outside the review page, so do not upload confidential drawings, unreleased footage or documents until private media storage is implemented.
